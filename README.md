Hi, I'm Modestas 👋

I'm researching parser generators.

My goal is parsers that are correct by construction and optimally efficient, so nobody has to write one by hand again. In particular, I'm focusing on bottom-up parsing, bringing existing research on more expressive parsing into practical tools and extending it where needed.

For a long time I've done this work privately. Now I'm starting to bring it out of the lab and put it to use. One of the first applications is fuzzing language implementations, which has already uncovered bugs in the parsers of the [Dart SDK](https://github.com/dart-lang/sdk/issues/64835) and [Drift](https://github.com/simolus3/drift/issues/3911).

Besides that, I'm working on [SIMD in Dart](https://github.com/dart-lang/sdk/issues/64170). I still do Flutter, but these days my focus is almost entirely on compilers.

If you're interested in any of this, I'd love to talk!
